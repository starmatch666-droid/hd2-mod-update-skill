# 05 · 排错日志对照表

| 日志（关键字） | 类别 | 含义 | 处置 |
|---|---|---|---|
| `unsupported_game_dll_no_write` | A | game.dll 哈希不匹配 | 刷锁（`hd2modupdate.py`） |
| `startup_failed_no_write … unsupported_game_dll_no_write` | A | 同上，启动阶段就退 | 刷锁 |
| `Discovery: N declared entries` 里没有你的 addon | A/归档 | 归档结构坏了（最常见：name_hash 被重算） | 用原 `name_hash` 重建；对比备份 |
| `not_found` / `anchor_mismatch` | B | 指针槽 RVA 变了 | 探针取新 `owner_rva` |
| `waiting_for_entity_locator` | B/依赖 | 依赖的定位器 addon 没装或加载失败 | 装/修定位器（注意 cdef 唯一名） |
| `template_mismatch` / `guard_failed` | C | 行模板/邻域指纹变了 | 探针 dump → 重算模板 |
| `ldld_block_not_found` | C | 目标表整体挪了/尺寸变了 | 探针 dump → 更新表地址/尺寸 |
| `write_failed_or_readback_mismatch` | 写入 | 写进去了但回读不一致（可能被游戏立刻重写） | 加**看门狗**周期复查并重写；确认是否进任务时游戏重建数据 |
| `attempt to redefine '_MEMORY_BASIC_INFORMATION'` | 加载 | 两个 addon 的 `ffi.cdef` 撞名 | 结构体改唯一名 + `pcall(ffi.cdef,…)` |
| `attempt to redefine …` 其它符号 | 加载 | 同上（含重复声明函数） | 同上 |
| addon 完全不出现在日志 | 归档/槽位 | 槽位链有空洞 / zip 不是 Arsenal 布局 / name_hash 错 | 检查连续性与归档结构 |

## 快速自检命令

```bash
python tools/hd2update.py verify <每个成品包>       # 旧锁清零
python tools/hd2update.py inspect <成品包>          # 结构 + addon 名 + 锁
# 游戏侧
grep -c "mods/" "%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\BingusSharedLoader.log"
grep -l "applied_runtime_write_verified" "%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\*.log"
```
